# Pinned, mutually compatible stack for CINECA Leonardo (verified July 2026).
#
# Leonardo Booster imposes TWO hard constraints that together rule out most
# recent vLLM/torch wheels:
#   1. GPU driver 535.x  => CUDA 12 only (a CUDA-13 build fails at torch init
#      with "The NVIDIA driver on your system is too old (found version 12020)").
#   2. RHEL 8 => glibc 2.28 (a wheel tagged manylinux_2_31/2_35 has no usable
#      build and pip falls back to a source build -> "CUDA_HOME is not set").
#
# vLLM wheel matrix vs. these constraints:
#   * vllm <= 0.19.x : CUDA 12.8 (good) BUT manylinux_2_31 -> glibc too new. no.
#   * vllm 0.20.x    : manylinux_2_35 -> glibc too new. no.
#   * vllm 0.22+     : manylinux_2_28 (glibc ok) BUT depends on nvidia-cutlass-dsl
#                      [cu13] / humming-kernels[cu13] -> CUDA 13. no.
#   * vllm 0.21.0    : manylinux_2_24 (glibc ok) AND no cu13 deps -> CUDA 12. YES.
#
# So we pin vllm 0.21.0 and force the CUDA-12.8 build of torch 2.11.0 via the
# +cu128 local version from PyTorch's cu128 index (manylinux_2_28, driver >=525
# through CUDA minor-version compatibility -> runs on the 535 driver). vllm's
# `torch==2.11.0` pin is satisfied by 2.11.0+cu128 (PEP 440 ignores the local
# label). Do not bump vllm/torch until CINECA upgrades the driver to >= 580.
#
# Install on a Leonardo LOGIN node (internet) via scripts/setup_leonardo.sh.
